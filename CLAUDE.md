# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

libredb.org — a static Astro site for LibreDB Studio. Bun is the runtime and package manager; there is no npm lockfile.

## Commands

```sh
bun run dev                       # localhost:4321
bun run gate                      # typecheck → format → lint → knip → build → test
bun run verify                    # gate + secretlint + Lighthouse a11y
bun run format:fix                # prettier --write (gate only checks)
```

`bun run gate` is the contract — CI runs it and `.githooks/pre-push` runs it locally. Run it before saying work is done.

**`bun test` needs a build first.** Several suites assert against `dist/`; `tests/setup.ts` (preloaded via `bunfig.toml`) throws with instructions if `dist/` is missing. `gate` does both in the right order.

```sh
bun run build && bun test tests/redirects.test.ts   # one file
bun test -t "lands on the anchor it promises"       # one test by name
bun run a11y --route /support --min 95              # one route
bun run serve                                       # serve dist on :4321
bun run cms                                         # Outstatic dashboard (needs cms/.env.local)
```

**`sirv` reads `dist/` once at startup.** After a rebuild, restart `bun run serve` — otherwise the new hashed CSS 404s silently and the page renders unstyled, which looks exactly like a broken CSS rule.

## Single sources of truth

The recurring bug in this repo's history is a **second copy of a list** that drifts. Several things exist specifically to prevent that; do not reintroduce a copy.

- **`site.config.json`** — domain, repo, external links, version, route inventory. `astro.config.mjs`, every canonical URL, the footer version chip and `llms.txt` derive from it. `tests/domain.test.ts` asserts `site.routes` against what `dist/` actually built.
- **`src/data/*.ts`** — all page copy. Components render; they do not hold prose.
- **`src/styles/ds/`** — a byte-identical copy of `design-system/`. **Never edit it**; `tests/ds-integrity.test.ts` hashes both. Site-level additions live beside it: `a11y.css` (contrast lifts, each with its measured ratio), `console.css`, `doc.css`, `prose.css`, `diagram.css`.
- **Generated text files** — `llms.txt`, `llms-full.txt` and `docker-compose.example.yml` are Astro endpoints (`src/pages/*.txt.ts`) rendering the same data the pages render. They were static files once and went stale in both directions.

Upstream facts (support matrices, channel lists, compose variables, engine limits) are transcribed from the sibling `libredb-studio` repo, and each data file names the exact file it came from. Verify against that source before changing a version number or a claim.

## Content conventions that tests enforce

This site's positioning is that it states limits. That is not a style preference here — it is checked:

- Every engine in `engines.ts` carries a `not` line; every feature in `features.ts` carries a `limit`. Both flow into `llms-full.txt` automatically.
- `/security` publishes SECURITY.md's known limitations next to the controls.
- `/compare` may **not** claim a named competitor lacks a feature. It compares architectural approaches; the rule is stated in `src/data/compare.ts` and a test forbids "unlike …" framing in the generated files.
- `/deploy` lists only channels with `status: live` in the studio repo's `channels.yaml`. A submitted-but-unmerged listing is not a listing.
- `/support` is read by certification reviewers as evidence. A version there must be traceable to a file in the studio repo.
- **English only.** `lang` is set once on `<html>`; a `lang` attribute anywhere below it fails `tests/dist-smoke.test.ts`. There is no per-post language field. (The vendor's Turkish legal name in `company.ts` is deliberate and stays ASCII — read its header before "fixing" the spelling.)

## Deploys — two environments, disjoint triggers

|          | Test              | Production                 |
| -------- | ----------------- | -------------------------- |
| Host     | Netlify           | GitHub Pages (libredb.org) |
| Fires on | push to `main`    | `release: published`       |
| Workflow | `deploy-test.yml` | `deploy.yml`               |

Merging to main must never publish production. `tests/domain.test.ts` asserts this from the workflows' `on:` blocks. `netlify.toml` exists only to send `X-Robots-Tag: noindex` on the test host; GitHub Pages never reads it.

Retired URLs from the previous site are tombstones generated by `src/pages/[...legacy]/index.html.ts` from `src/data/redirects.ts` — meta refresh + `location.replace` + canonical, since a static host cannot issue a 301. They are temporary and dated for review.

## Traps specific to this stack

- **`<pre>` is raw text to the Astro parser.** An expression returning markup inside one does not survive the compile. Emit an escaped HTML string and use `set:html`.
- **A `.astro` page cannot produce exact bytes.** The build attaches an extracted stylesheet and the prefetch module. Where the output must be minimal (redirect stubs) or non-HTML, use an endpoint at `src/pages/<name>.<ext>.ts` exporting `GET(): Response`. In a static build only the body survives — response headers are the host's.
- **Outstatic writes three kinds of empty**: absent key, empty string, and literal `null`. `zod`'s `.optional()` accepts only `undefined`, so `content.config.ts` uses `text()` / `list()` preprocessors. A bare `.optional()` fails the gate.
- **TypeScript is pinned to 6.x.** TS 7 ships no JS compiler API and `astro check` crashes on it.
- **The console palette is fixed dark** and does not flip with `[data-theme]` — a terminal is a terminal in both themes. Components reference `--console-*`, never the hex values.
- **Single-column prose blocks need an explicit `max-width`.** Two-column card grids get a readable measure for free; a one-column block inherits the container and runs past 100 characters a line. The rule is at the top of `doc.css`.
- **`compressHTML` is `'jsx'` by default in Astro 7** and strips newline-containing whitespace between inline elements — it once welded the hero headline into one word. `tests/dist-smoke.test.ts` guards it.
