Tooltip explains a truncated label, an icon-only control or a metric unit.

```jsx
<Tooltip label="Son 24 saat"><IconButton label="Bilgi" icon="i" /></Tooltip>
```

- Appears on focus as well as hover — a hover-only tooltip is inaccessible.
- If it needs a link or more than a few words, it is a popover, not a tooltip.
